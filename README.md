# The Other World Journal
Welcome to a journaling experience inspired by LAIKA Studio's, Coraline. With the release of their new movie, I thought it would be fun to pay bit of a homage to this absolute classic. 

This app was made for my little sis who is learning to type, however, you can also use this as you watch the Coraline movie. You can also use it to spark your imagination. 

## Features
Create, read, update, and delete (CRUD) personal journal entries

Secure user authentication and login (via Passport)

Practice typing in a fun, themed environment

Save and manage your imaginative thoughts

## Tech Stack
HTML/CSS/JavaScript: Frontend interface and styling

Node.js: Runtime environment

Express: Web server and application routes

Passport.js: User authentication

MVC Architecture: Structured with views, config, and public directories

How to Run Locally
Before running the project locally, make sure you have:

Node.js installed

A MongoDB account/database (if applicable for your CRUD operations)

Any necessary .env variables configured for Passport and your database

## Installation
Clone the repository and move into the project directory:

git clone https://github.com/desithomas/other-world-journal.git
cd other-world-journal
npm install
npm start
