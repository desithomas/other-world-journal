# The Other World Journal
Welcome to a journaling experience inspired by LAIKA Studio's, Coraline. With the release of their new movie, I thought it would be fun to pay bit of a homage to this classic. 

A private journaling app with a Coraline-inspired theme. Create an account, sign in, and write, save, and revisit your own journal entries in a space designed to spark imagination. 

## Tech Stack 
* **HTML/CSS/JavaScript:** Frontend interface and styling.
* **Node.js:** Runs the server.
* **Express:** Web server and application routes.
* **Passport.js:** User authentication.
* **MongoDB w/ Mongoose:** Database for users and journal entries.
* **EJS:** Server side page rendering.
* **MVC Architecture:** Structured with views, config, and public directories.

## How to Run Locally:

1. **Clone the repository:**
```bash
git clone https://github.com/desithomas/other-world-journal.git
cd other-world-journal
```
2. **Install the dependencies:**
```bash
npm install
```

3. **Create your .env file:**
* Create a .env file in the project root with the following: 
```bash
SESSION_SECRET=your-session-secret
```

4. **Start the application:**
```bash
npm start
```

5. **Local browser view:**
*Go to http://localhost:8081 

Viola! Please enjoy this Coraline themed application.
